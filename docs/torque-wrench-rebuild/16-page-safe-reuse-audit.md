## 1. Findings and evidence method

The viable reuse is below the legacy adapters. Numeric drawing/inspection samplers, CAD classification, sheet geometry, and the shaft runtime already offer useful seams. `TorqueWrenchHero`, `DrawingLinework`, root `CameraRig`, `InspectionScene`, `RingInspection`, and root hotspot composition require adapters/extraction. Their root stores, selectors, global proof surfaces, and frame clocks must not follow them into the private page.

The most consequential source findings are:

- `TorqueWrenchHero` registers ScrollTrigger at module scope, sets the global GLTF decoder path, and calls `useGLTF.preload('/models/Default.glb')` at module scope. Importing the module can initiate CAD loading before mounting the component (`src/scene/TorqueWrenchHero.tsx:1–47,117–161,472`).
- `DrawingLinework` reads/writes root scroll and quality stores; its `extractionPose` dependency also imports root quality. Explicitly supplying a tier to `applyExtraction` does **not** remove that module import or its initialization effects (`DrawingLinework.tsx:17–47`; `extractionPose.ts:5,164–173`; `src/state/qualityStore.ts:29–62`).
- `InspectionScene` eagerly imports and registers both runtime factories; `inspectionStore` snapshots/restores root `ScrollState`. The ring runtime imports that store; the shaft runtime does not have a runtime root-store edge (`src/scene/inspection/InspectionScene.tsx:3–17`; `src/state/inspectionStore.ts:3–5,54–105`; `ringRuntime.ts:3`; `shaft/shaftRuntime.ts:1–26`).
- Hero gear idle, CAD shader time, camera rest orbit, inspection playhead, and the scroll-commit assist depend on elapsed time or input history. Camera/lamp damping is a separate settling dependency. These cannot be silently treated as canonical progress (`TorqueWrenchHero.tsx:381–392,448`; `CameraRig.tsx:530–551`; `DrawingLinework.tsx:805–814`; `inspectionStore.ts:160–172`; `scrollCommit.ts:41–111`).

Codex-tiers routing: parent performs hero/rig/root lifecycle analysis, synthesis, and source spot-checks; native `tier-reader` performs bounded drawing/inspection gathering, configured Luna/high, with a self-contained read-only spec. Native permissions are inherited; the role name is not a filesystem sandbox. Backend identity/billing are not independently measured. The reader returned exact local references and an export/dependency addendum. Estimated reader whole-task overhead before launch: 15–30k tokens; exact dollar cost unavailable. One independent native `tier-reviewer`, configured Astra/medium, is used for document/source review; estimated additional whole-task cost: 15–25k tokens. Review is not implementation or gate approval.

Graph discovery used only `jgun-torque-wrench-rebuild`, whose registered root is this workspace. All 72 exact source paths checked reported `no_recorded_issue` with `metadata_changed`; the graph generation was 2026-10-10. Current source is authoritative.

# Work Intake

Use this folder for untriaged proposals, review findings, and imported plans that have not been accepted into the canonical queue. Name each file `YYYY-MM-DD-short-topic.md`.

A proposal must state its intended outcome, affected files or system areas, source material, unknowns, and whether it changes an existing `JG-###` plan. It is not an implementation authorization.

At triage, either reject or merge the proposal, or promote it by assigning the next stable ID, moving it to `../plans/`, adding a registry row in `../INDEX.md`, and creating an unchecked `TODO.md` entry in the same change.

## How these captures were taken (read this first)

- **Bundled Chromium 141.0.7390.37 with ANGLE/SwiftShader software GL, in a Linux cloud container.** Renderer string in every report: `ANGLE (Google, Vulkan 1.3.0 (SwiftShader Device (Subzero) (0x0000C0DE)), SwiftShader driver)`. Launch is the shared `scripts/lib/browser-launch.mjs` (Windows path unchanged; SwiftShader elsewhere).
- This is **NOT hardware GL.** **Windows hardware verification remains open.** The Windows D3D11/ANGLE desktop-full tier drop that makes G6 open (opening roster 5/6, desktop-full fails 110 expectations after the effective tier becomes lite, cause unestablished, no waiver) was **not** investigated or reproduced here.
- Every report says `qualityLock: true` (the `?qualityLock` proof parameter, added in `524bdb4`, stops the quality ratchet demoting a software renderer to poster). The `tier: "full"` value in the capture reports is therefore a **locked tier, not a tier, frame-rate or performance pass**, and is no evidence about G6 or about any full/lite budget.
- Captures use the existing proof hooks (`__drawingProof.setProgress`, `?inspectionProof` seek) with a settle gate, driven by `scripts/capture-owner-revisions.mjs` and `scripts/diag-shaft-artifacts.mjs`. Where a frame is dark or mid-reveal that is the scroll time requested, not a failed capture.
- Capture images are supporting context. Telemetry/unit assertions are the evidence of record (repo rule: vision alone confabulates on the dark scene).

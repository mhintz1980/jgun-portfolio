# G1 lifecycle and DOM shell integration contract

Scope: W1 store, descriptors/session resources, legacy load lease and RingInspection DOM/CSS only. Existing staged versions remain staged; this work is unstaged. Shared scene, camera, lights, post, hero and ring sampler were not edited. No commit, push or deployment.

## Runtime factory and readiness

`StoryRuntime` adds exactly `readonly root: Object3D` and `readonly ready: Promise<void>` to the reviewed interface. `StoryDescriptor.create(session, ctx)` remains synchronous. It constructs an instance-owned root, returns the runtime immediately, and starts session-owned async fetch/parse work. Pass `session.signal` to requests. `ready` resolves after required assets have parsed; it does not mean shaders are compiled or the store is ready.

W2 registers the real ring factory with `registerStory()`. Default ring metadata intentionally has no factory; the old scene remains its only adapter until W2 migration. No shaft descriptor, factory, trigger or static shaft substitute is installed. Shaft entry throws before acquiring ownership until a complete descriptor with required assets and a synchronous factory has been registered. Static shaft entry remains explicitly unavailable even with a registered runtime; it cannot fall through to the ring schematic. The shaft descriptor/static artwork remain later work. `getInspectionStory()` retains the immutable session metadata for DOM reads even if a factory registration is removed during teardown.

Integration order:

1. Enter captures narrative context and creates `inspection.session`. Obtain the registered descriptor and synchronously create its runtime with that session. Factories own their resources through `session.own()`; disposal removes the root, releases owned resources and is idempotent.
2. Call `setInspectionRuntime(runtime, session.id)`. It publishes the reference once and owns runtime disposal through the session. Repeating the assignment of the same instance is a no-op; assigning a stale instance disposes it and returns false. Mount `runtime.root` under the inspection world before awaiting `runtime.ready`. The runtime builds/fetches its assets under that instance-owned root; no camera writes.
3. After `ready` resolves, check `session.current()`. Dispose stale results immediately and do not attach, compile, publish controls or acquire camera/render leases for them. Capture the epoch in every rejection handler and use `session.fail(error)` or `inspectionFailed(error, session.id)`.
4. Publish `setInspectionStatus('compiling', session.id)`, apply lease-hidden narrative lighting, then perform the leased compile and 1px offscreen warm render, restoring renderer flags in `finally`. Check `session.current()` after each asynchronous step and again after warming. Only then call `setInspectionStatus('ready', session.id)`. Parsing alone cannot enable Play.
5. A single integration-owned priority -10 driver advances and samples; CameraRig and geometry/application readers consume `inspection.runtime` imperatively. W1 only exports `advanceInspectionPlayhead(delta, stamp)` and installs no production caller. The original baseline ring scene advanced time itself; integration must delete that advancement when installing the new driver. Final source refresh observed W2's new caller in InspectionScene.tsx:25 and real ring factory registration. These are concurrent W2 edits, not W1 changes or shell verification. Audio is not installed by this leaf; seek/chapter/replay produce no audio events here.

`inspection.playing` retains its compatibility setter so old ring/proof assignments update `userPlaying`; its getter derives effective playback from active/static/status/suspend/time. Frame advancement clamps delta to 0.05, rejects invalid/repeated/older stamps, holds at duration, and mutates scalars/telemetry without allocating or notifying on ordinary ticks. Chapter/end transitions alone notify. While hidden/context/error-suspended it advances neither time nor entryElapsed. Integration consumes `exiting` on its inactive frame; calling the exported advance function while inactive clears that one-frame marker.

`createStorySession(kind, lifecycle)` takes explicit `{ id, current, fail }` callbacks supplied by the store. This dependency injection is the implementation clarification to the contract's one-argument sketch: session and story modules have no runtime store import/cycle. Owned resources are disposed once, stale owned results are disposed immediately, and cached borrows are reference-counted and released without disposing the cache.

## DOM and restore

Play/Pause, Replay, labeled native seek and chapter commands use an epoch captured at render. Same-chapter paused seek does not broadcast; the DOM polls only visible time and updates the slider/output imperatively. Captions retain discrete status announcements. Ring has one chapter; chapter buttons appear only for registered multichapter stories. Entry is still the existing ring action; no shaft entry is exposed.

The dialog captures scroll coordinates, trigger, Lenis stop state, overflow, inert and chrome opacity in effect-local snapshots. It guards focusin/Tab/Escape, inerts newly inserted body siblings, restores original inert/opacity values and scroll, and resumes Lenis only if it was running. A disconnected trigger falls back to the current ring action, then the JGun chapter, then main/body; nonfocusable fallbacks retain a temporary tabindex until blur. Native focusable triggers retain their tab order. Return works while loading, compiling, failed and static. Retry cancels/restores the old epoch before opening a new paused session, with no delayed unscoped requestAnimationFrame callback.

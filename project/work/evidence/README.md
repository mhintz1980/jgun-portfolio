# Verification Evidence

Create one evidence record per accepted work ID at `JG-###-short-title-verification.md`, using [`../templates/verification.md`](../templates/verification.md).

A task may be checked off in `TODO.md` only after its evidence record is marked `verified`, names the current commit, and records the exact commands, runtime telemetry probes, quality tiers, and accessibility checks required by its accepted plan.

For failed or partial verification, retain the unchecked TODO item and record the blocker here and in the plan. Screenshots may support a finding but do not replace runtime telemetry for WebGL, rig, camera, material, timing, or performance claims.
